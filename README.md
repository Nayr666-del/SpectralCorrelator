# Qunatum Information Scrambling from a Spectral Perspective

We analyze correlator dynamics from spectral distributions of correlation operators. This repository contains the simulation and analysis files.

## Usage

lattice_site_v*.py runs the simulation according to a variety of different modes.

analysis_v4.py provides the analysis files. The science product includes:


radial.npy: eigenvalues at selected times

radial_weights.npy: weights of eigenvalues at selected times

params.npz: Parameter specifications of a specific run

L1_norm: L1 Distance to the limiting spectrum
